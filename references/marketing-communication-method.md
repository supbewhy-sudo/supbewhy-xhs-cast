## 使用原则

本文件只服务拆页前的内部判断。目标是让相关 TA 注意、理解、相信并采取与内容相符的行动，不是在上屏文字中堆营销术语。

按“目标 → 策略 → 页面与标题 → 可执行交接 → 完成检查”推进：

1. 目标：本次只促成一个首要变化
2. 策略：选择战略 TA，确定一个核心价值和认知位置
3. 页面与标题：用最少页面处理必要的场景、代价、价值、证据、疑虑和行动
4. 可执行交接：把结论写成最终上屏文字、素材位与视觉语义
5. 完成检查：确认内容获得的是有效注意力，并且没有牺牲真实性和长期形象

不要在日常输出中展示本流程、书名或框架名称。只输出会改变分页、标题、证据和 CTA 的结论。

## 内容类型路由

先判断主类型。混合内容选择承担传播目标的那个类型，不要平均使用多套路径。

| 内容类型 | 主要要改变什么 | 常见有效路径 | 合适 CTA | 避免 |
|---|---|---|---|---|
| 产品、服务、工具或 Skill | 从尚未理解，到愿意了解、验证或尝试 | 已知任务或输入 → 产品是什么与核心差异 → 工作方式 → 真实演示或证据 → 行动与边界 | 试用、安装、下载、咨询、购买前一步 | 功能目录、只讲品牌自述、隐藏使用成本 |
| 教程、方法或知识 | 从不会或做不对，到理解并完成一次 | 认出任务 → 看见常见误区或后果 → 掌握关键判断 → 跟着步骤完成 → 自查结果 | 立即做一步、保存到工作流、收藏备用 | 硬卖工具、为了钩子制造不存在的危险 |
| 观点、洞察或判断 | 从旧判断，到接受更准确的新判断 | 呈现旧判断 → 暴露它解释不了的事实 → 提出新判断 → 给出依据与边界 → 应用到一个决定 | 改一个判断标准、讨论、转发给相关人 | 把立场强度当证据、把有限观点绝对化 |
| 案例、复盘或成果 | 从看到结果，到理解可迁移的机制与边界 | 结果或冲突 → 起点与条件 → 关键决定 → 证据变化 → 可迁移经验与限制 | 对照自己的情况、采用一个机制 | 只晒结果、把相关性写成因果、隐去失败条件 |
| 资源、清单或推荐 | 从信息散乱，到能快速选择或执行 | 触发场景 → 选择标准 → 分组资源 → 使用方式 → 适用边界 | 收藏、领取、逐项检查、转发给需要的人 | 清单凑数、假装全部亲测、制造购买 CTA |

没有商业对象时，“营销传播”只表示让对应 TA 认出相关性，并愿意阅读、收藏、关注、应用或转发。不得虚构销售目标。

## 营销传播决策链

### 事实来源先于策略推断

先建立内部来源账本，再回答营销问题：

| 来源 | 处理方式 |
|---|---|
| 用户明示或已核实 | 可以用于策略摘要、标题、页面状态和画面文字 |
| 由明确目标直接产生的规划决定 | 可以决定内容类型、页序、分组和 CTA，但只写成规划，不描述成 TA 事实 |
| 材料没有提供 | 触发场景、当前替代、疑虑、前置认知和心理活动均标待确认，不补写 |

“需要分析”不等于“可以假设”。当材料只提供教程步骤或清单条目时，可以根据明确目标安排阅读顺序，但不能顺手补出“TA 平时靠记忆”“TA 只看表面”“TA 觉得有一页说明就够了”等旧行为。

三个容易被推断污染的字段必须先定位来源原句：场景需要明确时刻或任务阶段；替代需要明确旧做法、手工做法、竞品或不行动；疑虑需要明确疑问，或明确成本、风险和边界。TA 的目标任务和产品功能不能反推成替代方案。找不到来源片段就逐字段写“当前材料未提供；待确认”。

对象的排除边界不能反推读者错误认知或额外非目标。材料写“不提供云同步”时，直接讲“不提供云同步”即可；不要再增加“读者会把它当云同步”或“跨平台协作人群不在 TA 内”等材料未提供的判断。

分页时用内容状态代替猜测心理：

`尚未看到 / 分清 / 拿到某项已知信息 → 已经看到 / 分清 / 拿到 / 可以执行该信息`

承接也只指向下一页的已知内容。材料没有明示读者反应时，不写“读者会马上问”“读者担心”或“读者误以为”。

### 1. 选择唯一传播目标

只选择一个：

- 意识到问题
- 接受新判断
- 理解一个方法
- 相信一个产品或方案
- 尝试、安装、下载、咨询或购买
- 收藏、应用或持续关注

其他变化只能作为通往首要目标的中间状态。末页 CTA 必须直接对应首要目标。

### 2. 选择战略 TA

优先回答：

- 谁能从这项内容或对象中获得最明显的价值？
- TA 正在什么场景里做什么任务？
- 哪种行为说明 TA 真的有这个需要？
- 材料是否明确给出本次不重点说服谁？没有就不自行创造排除对象

战略 TA 是内容最有资格服务的人；平台标签、搜索词或触达渠道只是找到他们的方式。不要用“年轻人、职场人、所有创作者”等人口标签代替场景和任务。

### 3. 找到真实任务与触发场景

依次回答：

- 表面诉求：TA 说自己想要什么？
- 真实任务：TA 最终想完成什么或避免什么？
- 触发场景：哪个时刻让这件事从“以后再说”变成“现在要处理”？
- 现状代价：继续旧做法会浪费什么时间、操作、注意力或机会，带来什么麻烦或风险？
- 向往状态：完成后，工作、体验、心理或身份感发生什么可感知变化？

行为和真实场景优先于空泛口头偏好。没有真实产品或内容价值时，不用文案技巧掩盖。

### 4. 明确当前替代

替代方案不只包括竞品，也包括：

- 手工完成
- 用通用工具凑合
- 继续旧流程
- 请别人处理
- 忽略问题或不行动

内容必须建立在 TA 已有认知上。先说清 TA 现在怎样完成同一任务，再说明为什么值得改变。

## 价值、成本与认知位置

### 形成一个认知位置

内部形成以下结论：

- 品类或参照系：它是什么？读者会把它与什么放在一起理解？
- 必要共同点：作为这个品类，它至少必须做到什么？
- 核心差异：相对当前替代，哪一个差异最影响选择？
- 排除项：它不是什么？哪些期待需要主动纠正？
- 核心答案：读者看完整组后最该记住哪一句？

一个核心差异统领标题、功能和证据。其他功能只在能证明这个差异、解除疑虑或支持行动时保留。

### 翻译价值

不要停在功能。依次检查：

- 功能收益：能完成什么任务或减少什么错误？
- 体验收益：是否更省时间、步骤、切换、学习或等待？
- 心理收益：是否降低不确定、焦虑、失控或决策压力？
- 身份或社交收益：是否帮助 TA 成为想成为的角色，或更容易与他人协作？

同时盘点成本：

- 金钱
- 时间
- 学习
- 操作
- 迁移
- 授权或隐私
- 放弃其他选择的机会成本

核心价值不是收益清单。选择对战略 TA 最重要、证据最充分、与替代差异最清楚的一项作为主价值；成本决定是否需要独立页面、边界提示或更低门槛 CTA。

## 疑虑与证据

### 只记录有来源的疑虑

以下问题可以用于检查材料是否缺信息，但只有材料明确提出疑问，或已经核实相应成本、风险、限制时，才能写入“主要疑虑”并安排页面：

- 与我有什么关系？
- 为什么不能继续旧做法？
- 它是否真的有效或成立？
- 使用或理解是否复杂？
- 会不会产生功能、财务、心理、社交、隐私、授权或机会风险？
- 是否值得现在行动？

有来源时只保留最影响理解或行动的 1-3 项；没有来源时写“当前材料未提供；待确认”，不能把检查问题改写成读者疑虑。

### 再匹配证据

| 主张类型 | 优先证据 | 注意 |
|---|---|---|
| 它有什么功能或规则 | 实际界面、演示、文档、原始清单、官方来源 | 产品 README 能证明功能描述，不能自动证明效果 |
| 使用前后有什么变化 | 前后截图、完整案例、可复现演示、过程记录 | 说明起点、条件和边界，不把相关性写成因果 |
| 用户是否认可 | 可核实反馈、真实使用记录、独立评价 | 不虚构用户话术，不把单例写成普遍结论 |
| 数字或效果 | 数据来源、口径、样本和时间范围 | 缺任一关键条件就降级或删除数字 |
| 风险与边界 | 权限说明、迁移政策、适用条件、失败条件 | 明确“不会做什么”本身可以建立信任 |
| 教程或观点 | 可复现步骤、原始输出、事实依据、反例和适用边界 | 不用语气强度代替证明 |

证据的职责是推动一个具体判断，不是装饰页面。缺少证据时只允许三种处理：追问、删除主张、标为待补。不得用产品自述、形容词或设计感填补证据空位。

频率、排序、趋势和普遍性表达也属于证据主张。没有统计、样本或比较依据时，不写“最容易、容易、最常见、常见、通常、常常、大多数、最有效、首选、最短、最该”等词，改成材料能够直接支持的非比较陈述。检查范围是整份交付，不只检查标题。

“行业里常见”不能替代当前内容源。材料没有提供的具体例子、前置状态、数据类别或条目解释，不得被补写成当前对象的事实；能用已有上位概念说明时保持概括，否则标为待补。策略摘要需要但材料未明示的触发场景、当前替代或疑虑，逐字段直接写“当前材料未提供；待确认”；不能因为一个字段已知就补齐另外两个。只有用户明确要求策略建议时才可标成“建议推断；待确认”，且不能在页面任务、读者变化、标题、承接或上屏文字里改写成事实。

核心主张本身不自动生成疑虑。例如观点是“不应把摄像头当统一投入指标”，不能因此补出“镜头能否代表投入”“统一要求是否适用”等疑虑；这些只有在材料明示为真实阻力时才能进入 `主要疑虑`。

清单条目也不自动生成疑虑。把“确认隐私说明与实际行为一致”改成“隐私说明是否与实际行为一致”，只是句式变化，不是材料提供了读者疑问；没有另行明示的成本、风险或阻力时仍写“当前材料未提供；待确认”。

材料已经给出的检查项、功能、标准和边界只允许压缩、分组或排序，不新增判断维度、判定条件或结果解释。缺少解释时，策略账本可以暂时保留原始短标签，并把缺口放进待补证据位；公开页面不得把该标签直接当作最终主标题或正文。若当前证据不足以写出语义完整的公开表达，标记待补，不用标签填充页面。

清单条目不能用反向否定句制造张力。例如材料只写“检查第三方 SDK 或分析工具”，不要扩成“不只看自己写的代码”；材料只写“确认用户删除数据的路径”，不要增加入口、流程、结果等判定层。标题直接使用已知动作、对象或边界即可。

检查动作也不能被改成结果结论。“检查日志中是否含 Token 或用户内容”只能压缩为同义检查动作，不能写成“别留 Token”“日志里不能有 Token”。分组时可以在内部使用上位概念，但上屏仍保留“第三方 SDK 或分析工具”“用户删除数据的路径”等原词，不替换成材料没有的类别名。

价值表达优先写对象直接完成的动作或结构变化。没有结果证据时，不写“减少返工、降低风险、避免误判、提升效率、减少信任损耗”等预期效果或因果承诺。

## 阅读路径与分页

先根据当前材料判断读者已经知道什么、还缺哪项信息才能完成传播目标。只有材料明确给出疑问、不信任、麻烦或风险时，才把它当作真实阻力；否则按“尚未看到某项信息”安排页面，不补写心理障碍。

可用路径示例：

- 产品：已知任务或输入 → 产品是什么与核心差异 → 工作方式 → 真实演示或证据 → 行动与边界
- 教程：认出任务 → 分清关键判断 → 看演示 → 跟做 → 自查
- 观点：旧判断 → 解释缺口 → 新判断 → 依据与边界 → 应用
- 案例：结果 → 起点条件 → 关键决定 → 证据变化 → 可迁移经验
- 资源：触发场景 → 选择标准 → 资源分组 → 使用方式 → 收藏或执行

这些是决策逻辑，不是固定页数。默认仍用 3-5 页，并执行删除测试。

每页必须：

1. 只承担一个主要沟通任务
2. 让读者状态发生一次可描述且有来源锚点的变化
3. 回应一个场景、代价、价值、疑虑、证据或行动阻力
4. 让下一页承接当前页面之后仍需补足的已知信息

承接只描述下一页将补充的已知事实，不代写读者心理；只有材料明确给出问题时，才可把它写成读者问题。

不要用功能目录、文章章节或清单平均分组直接分页。若同一页能完成原理与短例子，就合并；若证据或风险会决定是否行动，就给它独立空间。

## 最终传播检查

完成分页和文案后，逐项检查：

| 检查项 | 通过条件 |
|---|---|
| 注意 | 封面能让战略 TA 认出自己的场景或决定，不依赖夸张和泛痛点 |
| 区分 | 与同类内容或当前替代有一个清楚差异，不是换标题的常识 |
| 位置 | 读者能说出它是什么、不是什么、最值得记住的利益是什么 |
| 关联 | 价值、证据和行动都能明确关联到内容对象，不会只记住一句孤立金句 |
| 放大 | 内容增加正面期待，同时没有因隐藏成本、绝对承诺或模糊边界制造新顾虑 |
| 长期一致 | 表达符合对象真实能力、证据和长期形象，不为一次点击透支信任 |

对新技术、新工具和新概念，再补查：

- 面向的是愿意探索的技术爱好者，还是需要确定结果的实用型用户？
- 面向实用型用户时，是否写清使用方法、复杂度、可信证据、风险边界和试用门槛？

任何一项不通过，返回策略摘要、页序或标题修正，不让制卡工具补判断。
